# Лабораторна робота №3 — Model Development

## Мета роботи

Отримати навички розробки моделей для передбачення.

## Виконані завдання

1. Побудовано модель простої лінійної регресії для прогнозування ціни автомобіля за об'ємом двигуна.
2. Побудовано модель множинної лінійної регресії з використанням normalized-losses та highway-mpg.
3. Створено поліноміальну модель 11-го степеня.
4. Порівняно моделі за показниками R² та MSE.

## Технології

- Python
- pandas
- scikit-learn
- NumPy

## Запуск програми

З кореневої папки репозиторію:

```bash
.venv/bin/python lab-03/main.py
```

## Результати

| Проста лінійна | 0.6522 | 11643888.01 |
| Множинна лінійна | 0.5059 | 16540056.41 |
| Поліноміальна (11-й степінь) | 0.7029 | 9945239.11 |

Найкращі показники на навчальних даних отримано для поліноміальної моделі 11-го степеня.
