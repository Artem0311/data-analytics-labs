# Лабораторна робота №2

**Дисципліна:** Дата аналітика  
**Тема:** Аналіз даних за допомогою Python

## Мета роботи

Отримати навички аналізу даних із використанням мови програмування Python.

## Виконані завдання

1. Кореляційна матриця для bore, stroke, compression-ratio та horsepower.
2. Кореляція між stroke та price.
3. Оцінка лінійної залежності.
4. Групування автомобілів за body-style та обчислення середньої ціни.
5. Кореляція Пірсона та P-value для wheel-base і price.
6. Кореляція Пірсона та P-value для horsepower і price.
7. Дисперсійний аналіз ANOVA.

## Використані бібліотеки

- pandas
- scipy

## Запуск програми

Із кореневого каталогу репозиторію після встановлення необхідних бібліотек:

```bash
.venv/bin/python lab-02/main.py
```
